# Getting help

| You have… | Go to |
| --- | --- |
| A question, an idea to talk through, or something to show | [Discussions](../../discussions) |
| Something that doesn't work | [A bug report](../../issues/new?template=bug_report.yml) |
| A feature you'd like | [A feature request](../../issues/new?template=feature_request.yml) |
| A security problem | [A private report](../../security/advisories/new) — never a public issue |
| A crash | Settings → About → **Send crash report** (it opens an issue with the report attached) |

Before opening an issue:

1. Update to the [latest release](../../releases/latest) — the panel's **Update** button does it.
2. Search [open and closed issues](../../issues?q=is%3Aissue); add a 👍 to an existing one rather than opening a
   duplicate.
3. Look in **What can it do?** (the "?" in the panel's footer): every shortcut, tool and setting is there.

Nabız is made in spare time. Issues are read, but there's no guaranteed response time and no private support by
email.
